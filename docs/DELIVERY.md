# CPA 额度、重置卡查询与关闭状态消费适配交付

当前源码版本：0.2.0。日期：2026-11-05。构建与打包产物在本地生成，不提交到仓库。

## 已完成

- 额度 GET：合成 fixture 解析、多账号/多窗口身份、null/0 区分、部分明细错误不隐藏额度。
- 重置卡 GET：单独服务端凭据加载、精确 origin/path 白名单、脱敏卡数；不与额度账号自动绑定。
- 服务：loopback、宿主 bearer、固定路由、无 CORS、超时、流式大小上限、拒绝所有重定向；不输出上游原始错误。
- 内存共享缓存：合并并发、TTL、失败退避、旧数据保留与期限、源时间标记。没有把 live 响应持久化。
- 原生读取适配和桌面兼容面板，分别打包。原生卡数明确不是百分比。
- 新消费请求适配器：用户提供的精确 POST、服务端 bearer、同一 GET 记录 account_id/workspace_id、每逻辑操作 UUID4；不需要卡片 ID/到期时间，未实现任何 CPA 管理层或 ChatGPT 直连。
- 账号级安全流程：显式账号/工作区，一次权益消耗说明与二次确认；取消零动作；服务端同账号单飞、跨客户端共用 UUID，目标变化拒绝且不偷换；不自动重试。运行前将脱敏操作日志写到项目外，重启不会遗忘不明结果。
- 超时/断线/未知 200 均结果未知，先手动刷新卡数和额度核对，不能仅凭数量变化解锁；仅验证过的 mock 成功响应触发成功刷新。真实响应合同尚未确认，生产判定器不声称成功。
- 0.2.0 包含消费适配和确认代码，生产 enabled=false，无配置/环境/UI 开关。本次真实消费 POST 次数为 0。
