# 0.3.0 面板优化

## 已实现

- 紧凑账号卡片和提供商标记，方案、可用/旧数据状态紧邻账号名。
- 配额池分组，宽屏双列额度窗口，窄屏单列。剩余比例突出显示，绿色/黄色/红色分别表示正常、低额度和接近耗尽；未知值不显示为零。
- 重置倒计时及新鲜度每分钟本地更新，返回页面立即校验；精确日期和成本单位可点击/键盘展开。到期只标为待读取，不自行推定额度恢复。
- 删除重复空成本占位；有成本/Token 时紧凑显示，单位和估算边界保持明确。
- “调整顺序”支持拖动、上下按钮、手柄聚焦后的键盘上下键；宿主实例 storage 保存脱敏账号 ID。刷新后保留，可恢复默认，新账号追加，存储失败有提示。
- 手动重置默认折叠，查询与消费保持区分，生产消费仍关闭。
- 账号状态与数据新鲜度分开显示，旧数据条纹弱化；读取失败保留样本但标为旧数据。可用和低额度统计只计新鲜样本。
- 同名同周期配额池使用稳定短标识。排序到边界后焦点转到手柄并播报位置；保存失败持续提示并支持独立重试，退出排序不丢失警告。

## 手机边界

OpenChamber 2.6.1 手机 App 不加载扩展面板；本次未修改宿主、开放网络端口或部署另一个服务。已有额度服务的 `/quota` 网页可在手机浏览器读取，但不是该 App 内页面，不同步本扩展的排序。完整使用方式见 `USAGE.md`。

本次修复与此前本地 0.3.0 改动一并按用户要求提交推送；构建 ZIP 不入 Git，不修改主力宿主程序、OpenCode、模型路由或生产消费开关。
